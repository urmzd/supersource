# 14-ml-statistics

## Summary
- Contains an `nlp/` folder with coursework-style NLP scripts and grammar exercises.
- Contains `r-exercises/` with R-based statistics exercises and datasets.
- Contains ML scripts extracted from notebooks (A1-A4, linear regression, clustering, PyTorch, framework).
- Languages include Python, Prolog, Perl, and R.

## Key takeaways
- Mix of rule-based parsing (DCG/Prolog) and statistical approaches (taggers/classifiers).
- R exercises are organized by numbered sets with local data files.
- Many scripts are lab-style and expect specific datasets or inputs.

## How to run
- For ML scripts: `python3 <file>` (ensure required packages are installed).
- See `14-ml-statistics/nlp/README.md` for per-file execution notes.
- See `14-ml-statistics/r-exercises/README.md` for R exercise execution notes.
