# r-exercises

## Summary
- R practice sets organized by `exercise-1` through `exercise-8`.
- Each exercise contains one or more `.r` scripts and associated data files (`.csv`, `.txt`).

## Key takeaways
- Scripts are mostly standalone analyses tied to local data files in the same folder.
- Some exercises include generated plots (`Rplots.pdf`).

## How to run
- From this folder, run a script with `Rscript <exercise-x>/<script>.r`.
- Ensure the working directory is the script's folder if it expects relative data paths.
