# nlp

## Summary
- Coursework and lab scripts including:
  - Assignment-style files (`a1q4.pl`, `a1q5.pl`, `a2q4.py`, `a2q5.py`, `a3q4.py`, `a3q5.py`, `a3q6.py`).
  - Prolog/DCG grammars (`dcg*.prolog`, `parse.prolog`, `task.prolog`, `prog1.prolog`).
  - Taggers and NLP utilities (`hmm_tagger.py`, `crf_tagger.py`, `brill_demo.py`, `ne_chunker_exercise.py`).
  - Lab exercises (`lab1-*`, `lab2-*`, `lab3-*`, `lab5-*`, `lab7-*`).

## Key takeaways
- Demonstrates both symbolic NLP (grammars, parsing) and statistical tagging.
- Many scripts are data-driven; check each file header for expected inputs.

## How to run
- Python: `python3 <file>` (some require extra packages or datasets).
- Prolog: load into a Prolog interpreter (e.g., `swipl`) and run the predicates.
- Perl: `perl <file>`.
